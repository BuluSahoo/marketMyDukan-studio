# MarketMyDukan Studio — Project Rules

Premium template-showcase platform for the MarketMyDukan digital agency.

## Stack (fixed)
Next.js (App Router) · React · strict TypeScript · styled-components · Lucide React · Framer Motion.
**Never** add Tailwind CSS. **No** backend/database in v1.

## Design system
- Colors: bg `#F7F6F2`, text `#171717`, accent `#E7A33E`, card `#FFFFFF`, muted `#777777`, border `#E8E6E0`.
- Fonts: Plus Jakarta Sans (headings), Inter (body) via `next/font` CSS variables.
- Never hardcode colors/fonts/spacing in components — use `theme` (src/styles/theme.ts) and `media` helpers.
- Minimal, elegant, spacious. Subtle animation only; respect `prefers-reduced-motion`.

## Responsive (mobile-first)
- Base styles = mobile (320–767). `media.tablet` ≥768, `media.desktop` ≥1024.
- No horizontal overflow. Touch targets ≥ 44px. Verify at 375, 768, 1440.

## Architecture
- `src/app` routes only; `src/components/{ui,layout,sections}` agency site components.
- `src/styles` theme + global styles; `src/config` site config; `src/types` shared types.
- `src/data` homepage sample content (showcase templates, steps, services). Never hardcode
  card data inside section components. Preview art lives in `public/previews` and is
  generated by `node scripts/generate-previews.mjs`.
- `src/templates/<category>/<template>/` — each template is self-contained and
  must NOT import from agency components/styles. Register in `src/templates/registry.ts`.
- Every category supports unlimited templates; never hardcode one template per category.
- Components using styled-components need `"use client"`. Keep SSR via `StyledComponentsRegistry`.
- Transient props use `$` prefix.

## Quality gates (must pass before finishing any task)
`npm run lint` · `npm run typecheck` · `npm run build`

## Accessibility
Semantic HTML, visible focus states, aria labels on icon buttons, keyboard-usable navigation.
